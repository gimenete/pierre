## Overview

<Notice variant="warning" icon={<IconCiWarningFill />}>

`@pierre/trees` is a file tree rendering library for building beautiful,
interactive file explorers. It provides flexible components for visualizing
hierarchical file structures with syntax highlighting, icons, and customizable
styling.

## Features

- **Hierarchical rendering** — Automatically builds tree structure from flat
  file paths
- **File icons** — Includes icons for common file types and folders
- **Customizable styling** — Full control over appearance via CSS variables
- **Interactive** — Expandable/collapsible folders with keyboard navigation
- **React & Vanilla** — Components for both React and vanilla JavaScript
